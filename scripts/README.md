# Scripts

Repo-managed helper scripts used by Hyprland bindings and user services.

## Scripts

- `open-hypr-shortcuts.sh`: ensures the Noctalia plugin is available, then
  toggles the Hypr shortcuts popup
- `rclone-mount.sh`: shared wrapper used by user services for rclone mounts
- `toggle-workspace-layout.sh`: toggles the active Hyprland workspace between
  `dwindle` and `scrolling`
